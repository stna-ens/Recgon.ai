<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/teams/[id]/inferred-skills/** | All 5 routes are session + verifyTeamAccess + IDOR-checked |
| GitHub OAuth callback → DB | Callback trusts the OAuth state cookie + GitHub-returned code; writes consent timestamp only when the cookie indicates the skill-mining variant |
| client → /scan | Rate limit at enqueue time; consent required (412) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-14 | Spoofing | OAuth callback CSRF / state mismatch | mitigate | Use existing github_connect_state cookie compare pattern from auth/callback/github/route.ts:8-9. Extend with a NEW cookie flavor github_skill_mining_state so consent flow does NOT silently piggyback on a regular project-import OAuth |
| T-02-15 | Tampering | IDOR on /inferred-skills/[skillId] PATCH | mitigate | Inside PATCH: getInferredSkill(skillId) → verify row.teamId === params.id AND getTeammateUserId(row.teammateId) === session.user.id. 404 on mismatch. **Tested deterministically** by `inferredSkills.api.test.ts` (cross-team row → 404 assertion) |
| T-02-16 | Information Disclosure | listing another teammate's inferred skills | mitigate | GET /api/teams/[id]/inferred-skills accepts optional ?userId= query but enforces userId === session.user.id unless target's teammate_profiles.visibility = 'team' AND requester is in same team. Default behavior = self-only |
| T-02-17 | Repudiation | reject not honored | mitigate | PATCH writes rejected_at = now() BEFORE returning 200; Plan 02 worker's listRejectedTags filter confirms round-trip; banner immediately reflects via optimistic UI + refetch |
| T-02-18 | Denial of Service | Re-scan spam | mitigate | Rate-limit gate inside /scan route: teammate_profiles.last_scan_at within 60 min → 429 with retryAfterMin. Cron drains every minute (existing /api/cron/llm-jobs), so on-demand vs scheduled cannot interleave to bypass cap. **Tested deterministically** by `inferredSkills.api.test.ts` (last_scan_at 30 min ago → 429 with retryAfterMin assertion) |
| T-02-19 | Information Disclosure | leaking team existence to non-member via 403 | mitigate | All 5 routes return 404 on verifyTeamAccess === null — never 403 (matches Phase 1 convention at profile/route.ts:113) |
</threat_model>
