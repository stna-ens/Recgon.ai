useEffect(() => {

### `src/app/api/recgon/tasks/[id]/reschedule/route.ts` (API route, NEW)

**Analog:** `src/app/api/recgon/tasks/[id]/assign/route.ts` (entire 158 lines — exact owner-only contract pattern)

**Imports + auth + role pattern** (lines 29-66):
```tsx
import { NextResponse } from 'next/server';
import { auth } from '@/auth';
import { getTask, /* ownerRescheduleTask */, logEvent } from '@/lib/recgon/storage';
import { verifyTeamAccess } from '@/lib/teamStorage';

export async function POST(request: Request, { params }: { params: Promise<{ id: string }> }) {
  const { id: taskId } = await params;

  // 1) Auth.
  const session = await auth();
  if (!session?.user?.id) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });

  // 2) Task exists?
  const task = await getTask(taskId);
  if (!task) return NextResponse.json({ error: 'Not found' }, { status: 404 });

  // 3) Owner role on the task's team.
  const role = await verifyTeamAccess(task.teamId, session.user.id);
  if (role !== 'owner') return NextResponse.json({ error: 'Access denied' }, { status: 403 });
```

**Body validation pattern** (lines 68-81 — adapt for `scheduledDate: string | null`):

let body: unknown;

  ? (body as { scheduledDate: unknown }).scheduledDate

// Allow null (unschedule) or YYYY-MM-DD string. Reject anything else.
if (scheduledDate !== null && (typeof scheduledDate !== 'string' || !/^\d{4}-\d{2}-\d{2}$/.test(scheduledDate))) {

**`ownerRescheduleTask` pattern** (mirror `deferTaskScheduledDate` shape — lines 638-653):
```ts
/**
 * Owner-driven reschedule (Phase 3.5). Distinct from deferTaskScheduledDate
 * (which is dispatcher-driven) so the schedule_note copy stays honest about
 * who moved the task. Allows null = "unschedule".
 *
 * Idempotent: writing the same date is a safe no-op overwrite.
 */
export async function ownerRescheduleTask(
  taskId: string,
  newDate: string | null,  // YYYY-MM-DD or null
  ownerUserId: string,
): Promise<void> {
  const { error } = await supabase
    .from('agent_tasks')
    .update({
      scheduled_date: newDate,
      schedule_note: newDate
        ? `Manually rescheduled to ${newDate} by team owner.`
        : 'Unscheduled by team owner.',
    })
    .eq('id', taskId);
  if (error) throw new Error(`ownerRescheduleTask failed: ${error.message}`);
}
```
