<objective>
**Gap 1 (VERIFICATION phase_3_1_gaps#1):** The dispatcher currently assigns tasks even when EVERY candidate has zero fit signals (`agent_tasks` row `beb5b3e9-...` had `mathBreakdown` all zeros and was assigned anyway). Live UAT on 2026-05-15 confirmed the rule "rank top, pick top, assign" produces zero-signal assignments that no Why-you sentence can honestly justify.

**Fix:** New `hasMinimumFit(breakdown)` rule — at least ONE of the three FIT signals (`skillOverlap`, `fitForKind`, `interestNudge`) must be above `SIGNAL_FLOOR = 0.15` for any candidate to be eligible. Availability and load headroom are TIEBREAKERS only, never sole reasons to assign. When no candidate passes this floor, the task stays `unassigned` with a new `triage_note='no_clear_fit'` marker.

**Coupling to Plan 03-05:** Plan 03-05 also produces a null `whyYouSentence` when the LLM can't ground the sentence. The dispatcher treats that null as the SAME refusal signal (separate triage note: `'no_grounded_reason'`) — if the LLM can't say why this person fits, the assignment doesn't happen. Both gaps share the same refusal pipeline.

**Purpose:** Recgon stops assigning ghost tasks. When the math AND the LLM agree there's no reason this teammate fits, the owner gets to triage instead of an assignee getting a black-box task.

**Output:**
- Pure `hasMinimumFit` helper in match.ts (testable, no side effects).
- Triage refusal path in dispatcher.ts both `runDispatch` (Pass 3) and `dispatchTask` (single-task path).
- New `triage_note` column on `agent_tasks` (additive nullable).
- `markTaskForTriage` storage helper.
- New return state `'triage'` joins the dispatch result vocabulary.
- DispatchResult counts triage separately so cron logs surface refusals.
</objective>

| Boundary | Description |
|----------|-------------|
| Cron → dispatcher | Untrusted timing — same cron may fire while a previous drain is still running. Triage write is idempotent (same note overwrites cleanly). |
| dispatcher → DB (markTaskForTriage) | Service-role write. Bounded to `triage_note` and clearing `assignee_id` — never escalates. |
| Plan 03-05 LLM response → dispatcher | Null sentence flows in as a refusal signal. Treated identically to math floor failure. |
