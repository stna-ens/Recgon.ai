<objective>
**Gap 2 (VERIFICATION phase_3_1_gaps#2):** The math-only Why-you path renders generic templates ("Your background matches what this task needs") that don't cite specific signals from the chosen teammate's actual profile or history. Live UAT on 2026-05-15 confirmed the copy reads as the system grading the teammate, not as a PM citing real evidence.

**Fix:** Always call the LLM for the Why-you sentence — pass the task spec + chosen teammate's profile + math breakdown to a new `WHY_YOU_GROUNDED` prompt and require the LLM to cite a signal that ACTUALLY exists in the candidate's payload. If the LLM can't ground the sentence (validation fails or provider chain dies), return null. The dispatcher (Plan 03-06) then treats null as "no grounded reason exists" — which couples this gap to Gap 1 (zero-signal refusal).

**Purpose:** Every assignment Recgon makes from now on has a Why-you sentence that cites a real signal (a skill the teammate confirmed, a recent task they completed, an interest they declared) — or no assignment happens. No more "your background matches what this task needs" black-box copy.

**Output:**
- New grounded-Why-you LLM call with anonymization + post-hoc grounding validator
- Math-only template path DELETED from `whyYou.ts`
- Renderer becomes a thin pre-rendered-sentence read
- Bias regression for the new prompt (separate fixture set, stub + env-gated real-LLM modes)
- Reasoning envelope stores the rendered sentence so storage/API/email/UI all read one value (no re-calling the LLM)
</objective>
