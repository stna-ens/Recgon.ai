## Phase Goal (plain English)

Lock in the bias-safety gate. Run the judge against 5 same-shaped-but-different-named candidate sets, repeatedly, and prove the LLM doesn't favor certain name vocabularies. This is the test that catches the worst-case Phase 3 failure: the AI PM quietly assigning fewer tasks to teammates with certain names. Two modes: a fast deterministic check on every PR (catches wiring regressions), and a slow real-LLM run nightly (catches actual model drift).

<objective>
1. Build `src/__tests__/judge.bias-regression.test.ts` — runs 5 fixtures × 30 trials = 150 calls.
2. Stubbed mode (default): a deterministic per-fixture seed cycles `{1,2,3}` to verify the bias-aggregation harness itself works.
3. Real-LLM mode (`JUDGE_BIAS_REAL_LLM=1`): calls `chatViaChain` for real and asserts no fixture's top-pick rate deviates > 15pp from the cross-fixture mean.
4. Polish the post-hoc content validator with the 4 edge cases caught during planning: empty sentence, unicode pronouns, capitalized candidate refs, numeric-word counting variants.
5. Document `JUDGE_BIAS_REAL_LLM` in `CLAUDE.md` Env section.
6. Add a GitHub Actions nightly workflow that runs the real-LLM mode and auto-opens an issue on failure.
7. Final goal-backward check: prove all 5 ROADMAP Phase 3 success criteria are met by Plans 01–04 cumulatively.

This is the LAST plan. Phase 3 only ships when stubbed-mode bias regression is GREEN AND real-LLM mode has been confirmed once (manually, before merge).
</objective>
