## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → POST `/api/teams/[id]/profile` | Untrusted body crosses here; the route is the auth + validation chokepoint. |
| POST handler → `chatViaChain` | Raw user text is interpolated into an LLM prompt (prompt-injection surface). |
| `chatViaChain` response → `upsertProfile` | LLM output is treated as untrusted (post-hoc canonical filter is the trust gate). |
| GET `/api/teams/[id]/profile?userId=...` → Supabase read | Visibility enforcement happens here, not in the client. |
