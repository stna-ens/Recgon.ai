## Phase Goal (plain English)

Take the pure decision from Plan 02 and **make it actually happen**. When the cron fires, this plan's code sends the email, writes the log row, updates the task, and — for Tier 3 — moves the task to a free day on the assignee's calendar. Also wires the owner's "Snooze N days" escape hatch.

<objective>
Replace the Plan 01 stub `sweepOverdueTeams()` with a real implementation that iterates teams, calls `decideOverdueAction`, executes the resulting action via a new `overdueRunner.ts` module, and returns aggregate counts. Add the snooze API route for owner control. All copy lives in `prompts.ts`. All email goes through the existing Resend helper.

Purpose: this is where the policy meets reality. After this plan ships, an overdue task gets a nudge email tomorrow morning. A teammate sees the banner. The owner sees the escalation badge.

`sweepOverdueTeams` outline (in `src/lib/recgon/storage.ts`, replacing Plan 01 stub):

```typescript
export async function sweepOverdueTeams(today: Date = new Date()): Promise<{
  teamsProcessed: number;
  actionsByKind: Record<'nudge_teammate' | 'escalate_to_owner' | 'auto_reschedule' | 'none', number>;
}> {
  const teams = await listTeamsWithOverduePressureEnabled();
  let actions = { nudge_teammate: 0, escalate_to_owner: 0, auto_reschedule: 0, none: 0 };
  for (const team of teams) {
    const tasks = await listActiveTasksWithSchedule(team.id);
    const teammates = await listTeammatesWithStats(team.id);
    const owner = await getTeamOwner(team.id);
    for (const task of tasks) {
      const action = decideOverdueAction({
        task, teamOverduePressureEnabled: true, today,
      });
      if (action.kind === 'none') { actions.none++; continue; }
      const teammate = teammates.find((tm) => tm.id === task.assignedTo);
      if (!teammate) { actions.none++; continue; }
      await executeOverdueAction(task, action, teammate, owner);
      actions[action.kind]++;
    }
  }
  return { teamsProcessed: teams.length, actionsByKind: actions };
}
```

`executeOverdueAction` in `src/lib/recgon/overdueRunner.ts`:

```typescript
export async function executeOverdueAction(
  task: AgentTask,
  action: OverdueAction,
  teammate: TeammateWithStats,
  owner: { email: string; nickname: string },
): Promise<void> {
  if (action.kind === 'none') return;
  if (action.kind === 'nudge_teammate') {
    await sendOverdueNudge({ to: teammate.email, taskTitle: task.title, daysOverdue: ... });
    await markOverdueAction(task.id, 1, 'nudged');
  }
  if (action.kind === 'escalate_to_owner') {
    await sendOverdueEscalation({ to: owner.email, assigneeName: teammate.displayName, taskTitle: task.title, daysOverdue: ... });
    await markOverdueAction(task.id, 2, 'escalated');
  }
  if (action.kind === 'auto_reschedule') {
    const plan = await buildSchedulePlan(task, teammate);
    if (plan) {
      const originalDate = task.scheduledDate;
      await setTaskSchedule(task.id, {
        scheduledDate: plan.scheduledDate,
        scheduledUntilDate: plan.scheduledUntilDate ?? null,
        deadline: plan.deadline,
        scheduleNote: `auto-rescheduled from ${originalDate} (was ${daysOverdue}d overdue)`,
      });
      await sendAutoReschedulNotice({ to: teammate.email, taskTitle: task.title, newDate: plan.scheduledDate });
      await markOverdueAction(task.id, 3, 'auto_rescheduled');
    } else {
      // No capacity — hand off to reassignment.
      await reassignTask(task.id, null, 'recgon');
      await markOverdueAction(task.id, 3, 'auto_rescheduled');
    }
  }
}
```

Snooze route (`src/app/api/teams/[id]/tasks/[taskId]/snooze/route.ts`):

```typescript
export async function POST(request: NextRequest, { params }: { params: Promise<{ id: string; taskId: string }> }) {
  const { id: teamId, taskId } = await params;
  const session = await auth();
  if (!session?.user?.id) return NextResponse.json({ error: 'unauthorized' }, { status: 401 });
  const role = await verifyTeamAccess(teamId, session.user.id);
  if (role !== 'owner') return NextResponse.json({ error: 'forbidden' }, { status: 403 });
  const { days } = await request.json();
  if (!Number.isInteger(days) || days < 1 || days > 30) {
    return NextResponse.json({ error: 'days must be integer 1-30' }, { status: 400 });
  }
  await snoozeTask(taskId, days);
  return NextResponse.json({ ok: true });
}
```
