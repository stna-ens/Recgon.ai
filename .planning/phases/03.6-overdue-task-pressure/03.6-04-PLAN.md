## Phase Goal (plain English)

Make overdue visible. A red chip on the card, a tier badge for the owner, a "Snooze" button when the system gets it wrong, and counters in the logs so you can see how often the policy fires. Plumbing and policy ship in earlier plans; this one is the part you actually see.

<objective>

Purpose: close the loop so the dispatcher's new pressure behavior is legible to humans, not just emails.
</objective>

Derived `isOverdue` helper (in `src/lib/recgon/overduePolicy.ts` if Plan 02 hasn't already exported it, otherwise re-use):

```typescript
export function isOverdue(task: Pick<AgentTask, 'status' | 'scheduledDate' | 'scheduledUntilDate'>, today: Date): boolean {
  if (!task.scheduledDate) return false;
  if (!ACTIVE_OVERDUE_STATUSES.includes(task.status as any)) return false;
  const endKey = task.scheduledUntilDate && task.scheduledUntilDate > task.scheduledDate
    ? task.scheduledUntilDate
    : task.scheduledDate;
  return daysOverdue(endKey, today) >= 1;
}
```

OverdueChip:

```tsx
function OverdueChip({ tier, days }: { tier: 0 | 1 | 2 | 3; days: number }) {
  const variant =
    tier >= 3 ? { color: 'var(--danger)', filled: true } :
    tier === 2 ? { color: 'var(--warning)', filled: false } :
    { color: 'var(--signature)', filled: false };
  const label = days === 1 ? '1 day late' : `${days} days late`;
  return (
    <span className="overdue-chip" data-tier={tier} style={{
      borderColor: variant.color,
      background: variant.filled ? variant.color : 'transparent',
      color: variant.filled ? '#fff' : variant.color,
    }}>{label}</span>
  );
}
```
