<objective>
Ship the walking skeleton end-to-end for personalized task framing: a `task_reframe` job kind is queued post-assignment (never inline), a worker drains it, calls `chatViaProviders` once with a bounded-tone prompt, validates the output against a Zod schema + post-hoc grounding validator (FRAME-06 tone, FRAME-07 no external inference), and persists the result to two new additive columns on `agent_tasks`.

Purpose: Establish the foundation that Plan 02 (viewer-discriminated read) and Plan 03 (reassignment invalidation + golden tests) build on. This plan delivers an assignee viewing the API output of `/api/recgon/tasks/[id]` and seeing a populated `personalized_description` field after one cron cycle — the smoke test of the whole phase.

Output: Migration file, pure `reframe.ts` module, `task_reframe` worker, dispatcher hook that enqueues post-assignTask, two new schemas/prompts.
</objective>
